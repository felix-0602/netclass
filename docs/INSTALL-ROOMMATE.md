# Netclass Sidekick — 5 分钟装机指南（给舍友）

> 目标：从零到在 chaoxing 课程页看到蓝色小药丸出现、视频自动播放、答题自动勾选。
> 总耗时：5 分钟（不含下载时间）。
> 需要：一张 Netclass 卡密（格式 `NSK-XXXXXXXX-XXXXXXXX`）。找我要。

---

## 1. 装浏览器扩展 Tampermonkey

| 浏览器 | 装链接 |
|---|---|
| Chrome / Edge | https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo |
| Firefox | https://addons.mozilla.org/firefox/addon/tampermonkey/ |

装完浏览器右上角会有一个**黑底白点**的图标（Tampermonkey 标志）。

## 2. 开 Chrome 的"开发者模式"

**Chrome / Edge 必须开**（Firefox 跳过这步）：

1. 地址栏输 `chrome://extensions`（Edge 用 `edge://extensions`）
2. 页面**右上角** 打开"开发者模式"开关
3. 确认 Tampermonkey 是启用状态

## 3. 装 Netclass Sidekick 脚本

**方法 A · 拖文件（推荐）**

我会发给你一个叫 `netclass-sidekick.user.js` 的文件（约 800 KB）。

1. 点浏览器右上角 Tampermonkey 图标 → 选 **管理面板**
2. 把 `.user.js` 文件**拖到**这个管理面板页面里
3. 会弹出一个脚本预览页，点左下角 **安装**

**方法 B · 如果拖不行**

右键 `.user.js` 选"用 Chrome 打开" → Tampermonkey 自动接管 → 点 **安装**。

## 4. 确认装上了

回 Tampermonkey 管理面板，应该看到一行：

```
✅ Netclass Sidekick (alpha)   0.1.0-alpha   已启用
```

## 5. 激活卡密（关键步骤）

1. 打开你学校的学习通（地址通常是 `https://mooc1.chaoxing.com` 或学校域名挂的超星入口）
2. 正常**登录**你的学生账号
3. 进入**任何一门课程**的学习页（视频 / 作业都行）
4. 屏幕**左下角**会出现一个**蓝色小药丸**（带灰色点 + 文字"未激活"）
5. **点一下**药丸，展开完整面板
6. 点 **激活卡密** 按钮
7. 弹出的对话框里：
   - 服务端地址：保持默认 `http://182.254.180.181:8080`（不用改）
   - 卡密：粘贴我发你的那串 `NSK-XXXXXXXX-XXXXXXXX`
8. 点 **激活**
9. Tampermonkey 右上角**可能**弹一个"允许跨域访问 182.254.180.181 吗？"的确认 —— 选 **始终允许**
10. 几秒后对话框自动关，你会看到药丸变成**绿点** + 显示你卡密的前后 4 位（`NSK-…XXXX`）

**一次激活永久有效**，刷新页面不需要重输。

## 6. 验证脚本在工作

### 视频自动播放
随便点开一节视频任务点 → 视频**自动以 1.5 倍速播放**、静音、播完 3 秒后**自动跳下一节**。你可以挂后台不管（tab 被切到后台也不影响）。

### 作业 / 测验自动答题
点开一个**章节测验**或作业 → 药丸会变成**黄色脉动点**（表示"工作中"） → 面板展开能看到"答题进度 X/Y" → 选项会被**自动勾选**。

如果某些题服务端没答案（第一次有人做这题），面板会显示"N 待"，意味着已经上传队列、稍后有答案就自动答。

## 7. 排查

| 症状 | 可能原因 | 怎么解决 |
|---|---|---|
| 药丸根本不出现 | 当前页面不在脚本识别范围 | 看地址栏，域名必须含 `chaoxing.com` / `edu.cn` / `unipus.cn` 等 |
| 药丸出现但点激活转圈不动 | Tampermonkey 没批跨域 | 右上角找授权弹窗，点"始终允许" |
| 报"网络错误" | 服务端连不通 | 另开一个 tab 访问 http://182.254.180.181:8080/auth ，看是不是返回 `{"error":...}` |
| 报"卡密无效" | 卡密拼错 | 重新粘贴，全大写 + 横线 |
| 报"此卡密已绑定 3 个设备" | 卡密是按设备数限的 | 找我解绑或换张卡密 |
| 视频没自动播 | 浏览器拦截了自动播放（少数浏览器） | 手动点一次播放按钮，脚本接管后续 |
| 答题没自动勾选 | 可能是没支持的题型（图片选项/特殊富文本） | 手动做这题，没事儿，脚本别的题能答 |

## 8. 看日志（debug 才用）

**按 F12** → **Console 标签** → 过滤 `netclass-sidekick`，应该看到：

```
[netclass-sidekick] booting on chaoxing
[netclass-sidekick] panel mounted on chaoxing @ mooc1.chaoxing.com (shadow DOM)
[netclass-sidekick] auto-scan (initial boot) kind=chaoxing-chapter
[netclass-sidekick/filler] answered 3/3
```

正常情况看不到红字错误。看到红字截图发我。

## 9. 你帮我验证的事（Phase 0 门槛）

装好以后请按这个顺序做一遍：

1. ✅ 随便点进一节视频，不管它，**放任它自己播完 3 节**。回来检查：有 3 节被标"已完成"？
2. ✅ 做一次章节测验，看"答题进度"能不能涨到 N/N。没答全的题记下来哪题没答。
3. ✅ 试一次你另外一门**非数学**的课（英语、政治、概念课）—— 单选题答得对不对？
4. ⏸ 如果你也有**高等数学**课，先**不要**让它自动答（数学需要图片识别，Phase 0 还没接完）。碰到数学题手动做即可。
5. 📨 用 3-5 天，碰到任何问题（哪怕是"感觉不对劲"）发消息给我。

**我不会在你旁边帮你**。整个过程全靠你自己 —— 这是 Phase 0 退出门槛的核心条件。

## 10. 常见问题

**Q: 会被学校 / 超星检测到吗？**  
A: 目前没有。视频"切后台"、"鼠标不在视频上"这些检测我们都已经绕开。但请**别到处宣传**、**别发 QQ 群**、**别把卡密给别人用**。被人举报了服务端 7 天内就会被学校知道。

**Q: 我有多台设备能装吗？**  
A: 一张卡密最多绑 3 台设备（手机/平板浏览器也算）。超了来找我解绑。

**Q: 这个工具永久有效吗？**  
A: lifetime 卡密是的，月订的 7 天续一次 JWT。服务端我在上学期间会一直维护。

**Q: 我不会用 F12 怎么办？**  
A: 不用会。F12 是给我看日志用的，你直接告诉我"什么情况"就行。
